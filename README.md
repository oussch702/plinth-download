# Plinth pour Windows

Le logiciel Plinth dans sa propre fenêtre : toutes les touches d'Archicad, un fichier `.plinth` ouvert par double-clic, un `.ifc` par « Ouvrir avec › Plinth », une vue sur un second écran. C'est le même Plinth que dans le navigateur (https://plinth-1bpm.onrender.com), avec les mêmes comptes et les mêmes projets.

## Télécharger

- **Installateur** : [Plinth-Setup.exe](https://github.com/oussch702/plinth-download/releases/latest/download/Plinth-Setup.exe) (sans droits administrateur)
- **Sans installation** : [Plinth-win-x64.zip](https://github.com/oussch702/plinth-download/releases/latest/download/Plinth-win-x64.zip) (décompresser, puis lancer Plinth.exe)

L'installateur n'est pas encore signé : Windows affiche « éditeur inconnu ». Cliquez « Informations complémentaires », puis « Exécuter quand même ».

Windows 10 ou 11, 64 bits. Une connexion Internet est nécessaire.
